# Algorithm Exercises

## Overview
This project contains implementations of a range of interesting and challenging basic and intermediate algorithmic problems using C#.

## Topics Covered

- Fibonacci Sequence (Iterative and Fast Doubling)
- Balanced Brackets (Stack)
- Two Sum (HashSet)
- Digit Counting
- Sum of Digits
- Prime Number Detection
- Palindrome Detection
- Greatest Common Divisor (Euclidean Algorithm)
- Number Reversal
- Decimal to Binary Conversion
- String Permutations (Backtracking)
- Duplicate Detection (HashSet)
